TASK: Synthesize all assessments into actionable learning outcomes for a specific student.

STUDENT INFORMATION:
- Student ID: {{student_id}}
- Role: {{student_role}}
- Name: {{student_name}}

SCENARIO CONTEXT:
{{scenario_summary}}

CLINICAL SKILLS ASSESSMENT SUMMARY:
{{clinical_skills_summary}}

NON-TECHNICAL SKILLS ASSESSMENT SUMMARY:
{{nts_summary}}

CRM REFLECTION SUMMARY:
{{crm_summary}}

KEY MOMENTS FOR THIS STUDENT:
{{student_moments}}

Generate learning outcomes following this structure:

1. KEY ACHIEVEMENTS (What the student did well)
   - List 3-5 specific achievements
   - Reference specific moments/observations
   - Acknowledge clinical competencies demonstrated

2. AREAS FOR IMPROVEMENT (Specific areas needing work)
   - List 2-4 specific areas
   - Be constructive and specific
   - Link to observable behaviors

3. RECOMMENDED FOCUS (Priority areas for future practice)
   - List 2-3 priority focus areas
   - Consider urgency and impact
   - Align with learning objectives

4. ACTION PLAN (Specific action items)
   - List 3-5 concrete, actionable items
   - Each should be SMART (Specific, Measurable, Achievable, Relevant, Time-bound)
   - Include resources or references where helpful

5. DEBRIEF SUMMARY (Brief summary for discussion)
   - 2-3 sentence summary of key debrief points
   - Suitable for verbal delivery during debrief session

OUTPUT FORMAT:
Return a JSON object:
{{
  "key_achievements": ["string", ...],
  "areas_for_improvement": ["string", ...],
  "recommended_focus": ["string", ...],
  "action_plan": ["string", ...],
  "debrief_summary": "string"
}}

IMPORTANT:
- Be constructive and educational in tone
- Balance positive feedback with areas for growth
- Make action items specific and actionable
- The debrief summary should be suitable for verbal delivery
